📋 API Endpoints

Method Endpoint คำอธิบาย
POST /api/falls รับแจ้งเตือนหกล้มจาก ESP32
GET /api/falls ดูรายการเหตุการณ์หกล้มทั้งหมด
GET /api/falls/:id ดูเหตุการณ์หกล้มเฉพาะ ID
PUT /api/falls/:id/acknowledge ยืนยันรับทราบเหตุการณ์
GET /api/falls/stats/today สถิติหกล้มวันนี้
POST /api/position รับข้อมูลตำแหน่งจากอุปกรณ์
GET /api/position/devices ตำแหน่งอุปกรณ์ทั้งหมดที่ออนไลน์
POST /api/chat ส่งข้อความถาม Gemini AI
GET /api/stats สถิติรวมทั้งหมด
GET /api/health ตรวจสอบสถานะเซิร์ฟเวอร์

🔧 การต่อวงจร Hardware1

ตาราง Pin ที่ใช้เชื่อมต่อ MPU-6050 และ Buzzer กับ ESP32

ชิ้นส่วน ขา ขา ESP32 ประเภท
MPU-6050 SDA GPIO 21 Sensor
MPU-6050 SCL GPIO 22 Sensor
MPU-6050 VCC 3.3V Power
MPU-6050 GND GND Power
Buzzer (+) ขาบวก GPIO 2 (D2) Alert
Buzzer (-) ขาลบ GND Power

📖 คู่มือการใช้งาน

เริ่มเซิร์ฟเวอร์

cd Software && npm install && node server.js

เปิด Dashboard ที่ http://localhost:3000

เทรนโมเดล TinyML

cd Hardware1/tinyml && pip install numpy pandas scikit-learn

python train_model.py

จะสร้างไฟล์ fall_model.h อัตโนมัติ

อัปโหลดเฟิร์มแวร์ ESP32

cd Hardware1 && pio run --target upload

cd Hardware2 && pio run --target upload

ใช้ PlatformIO CLI หรือ VSCode Extension

ตั้งค่าหน้าเว็บ
